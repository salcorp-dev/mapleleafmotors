How It Works

A plain-language guide to the Maple Leaf Motors command center. Everything here updates live across all devices.

The big picture

Your website and this dashboard are connected through a small program running on Cloudflare (a “Worker”) plus a secure database (“KV”). When someone fills out the finance form on the website, it’s saved instantly and shows up here as a lead. Any change you make here — status, notes, inventory, client photos — is saved to the same place, so every admin sees the same up-to-date information. You don’t need to install anything; just log in at /admin from any browser.

1. Finance Leads

Your main workspace — every customer who submits the website finance form lands here.

  • New leads are highlighted and counted at the top. A lead older than 24–48 hours with no progress gets an age badge so nothing slips.
  • Status tracks where each customer is. Move them along as you work: New Lead → Contacted → Application Sent → Dealertrack Submitted → Approved → Needs Cosigner → Vehicle Selected → Delivered (or Lost).
  • Notes let you record anything about the customer. Click Save on a row to store status and notes.
  • Search & filters at the top help you find leads by name, status, or who they’re assigned to.
  • Assign (admins only) hands a lead to a specific salesperson — they’ll then see it in their own login.

2. Pipeline

The same leads shown as a visual board. The conversion strip shows how many leads reach each stage, and the kanban board groups every lead into columns by status — a quick way to see the health of your whole pipeline at a glance.

3. Marketing & Meta Pixel Admin only

How your Facebook / Instagram advertising connects to real leads.

  • A Meta Pixel (ID 1078447861507419) is installed on every public page. It records a PageView when someone visits and a Lead when they submit the finance form.
  • This tab turns the tracking your leads already carry (which ad, campaign, or source they came from) into simple charts: leads by source, top campaigns, and recent paid-social leads.
  • The numbers here come from your own leads. The full ad metrics — spend, reach, cost per lead — live in Meta, so the Events Manager and Ads Manager buttons link you straight there.

4. Meta Conversions API Admin only

Server-side tracking — set this up once in the Account tab.

  • The browser pixel can be blocked by ad blockers, iPhones, and browser privacy settings. The Conversions API fixes that by sending the Lead event from the server, where nothing can block it — so Meta sees more of your real conversions.
  • To turn it on: Account tab → Meta Conversions API → paste your access token → Save. The status shows Connected once it’s working.
  • The browser pixel and the server both report the same lead, but they share a hidden ID so Meta counts it once, not twice.
  • For security the token is write-only: after you save it, it’s never shown again and can’t be read back out of the dashboard. Replace it anytime to rotate it, or Remove it to switch server tracking off.

5. Live Inventory Admin only

Add, edit, and remove the vehicles shown on the website. Changes publish to the live site right away. You can also import vehicles from Listing Studio JSON in the Account tab.

6. Our Clients Admin only

Manage the delivery photos and customer testimonials that appear on the website’s “Our Clients” showcase. Upload a photo or testimonial here and it appears on the public site.

7. Accounts & roles Admin only

  • Admin (you) sees everything: all leads, marketing, inventory, clients, and account management.
  • Sales users have a simpler view — they only see the leads assigned to them, plus the pipeline and their own account settings. Admin-only tabs are hidden from them.
  • Create a new login in the Accounts tab: enter a name, username, role, and a temporary password (12+ characters). They can change their own password later.

8. Your Account

  • Change your password anytime — it’s saved securely and works on every device next time you log in.
  • Passwords are stored hashed (scrambled one-way), so no one — not even an admin — can read them. If one is forgotten, it’s reset, not recovered.
  • The Meta Conversions API token and Listing Studio import also live here.

Good to know

  • It’s all live. There’s no “publish” button for leads or status — changes save as you make them and sync to every admin.
  • After an update, refresh. If something looks off right after we’ve made a change, do a hard refresh (Ctrl+F5) to load the newest version.
  • Privacy. The form only collects what’s needed to match a vehicle; the pixel/CAPI track conversions, not sensitive financial details.
  • Stuck? Note what you clicked and what happened, and reach out — most issues are quick to fix.
